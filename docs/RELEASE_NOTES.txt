# v.1.0.0
- Primera versión publicada.
- ApiResult: resultado estándar para respuestas de API, con Success, Status, Title, Message, Data, Errors, TraceId y Exception.
- Resultados correctos con ApiResult.Ok(), con o sin opciones.
- Resultados de error con ApiResult.BadRequest(...) (mensaje, lista de mensajes o errores por campo) y ApiResult.Error(...).
- Requiere .NET 10 y Kitpymes.Core.Shared 2.0.1.
